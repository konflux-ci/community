# Maintainers

## Governance Committee

The Governance Committee holds project-wide authority over Konflux CI. Current members, terms, and the election process are defined in [governance.md](governance.md).

## Repository Maintainers

Each repository defines its own maintainers via a `CODEOWNERS` file. The full list of repositories is under the [konflux-ci](https://github.com/konflux-ci) GitHub organization.
